# EdgeTrash

Edge AI side of a trash-seeking TurtleBot3: **dataset, models, optimisation and a whole-pipeline benchmark** across edge devices (Pi4 CPU, Pi5 CPU, Pi5 + Hailo-8L, OAK-D Pro VPU).
Edge AI project (Université Côte d'Azur, G. Rocher). Robot counterpart: **[TrashLocalisation](https://github.com/TrashRobotEdge/TrashLocalisation)**.

> **Status: benchmark kit.** Pipeline runs end to end on the VM with COCO weights (dry run, `results/raw/vm/`). Device runs: class 01–02/12.
> Board: https://github.com/orgs/TrashRobotEdge/projects/1 · Plan: [TrashLocalisation/docs/PROJECT_PLAN.md](https://github.com/TrashRobotEdge/TrashLocalisation/blob/main/docs/PROJECT_PLAN.md)

## Layout
| Folder | What |
|---|---|
| `edgetrash/` | ROS-free inference library: preprocess → infer → postprocess per backend, with per-stage timers. Also used by the robot's `trash_detector` node ([ADR 0001](https://github.com/TrashRobotEdge/TrashLocalisation/blob/main/docs/decisions/0001-two-repos-shared-inference-lib.md)) |
| `bench/` | L1 benchmark harness (replayed frames, every device), configs, analysis |
| `setup/` | **one setup script for every device** (`setup.sh`) + the USB bundle for the Pis |
| `results/raw/` | Every raw log/CSV we measured (kept in git: small, needed to reproduce figures) |
| `results/figures/` | Figures, **generated by scripts only** |
| `data/` | Dataset spec (data itself is stored outside git) |
| `models/` | Train, prune, export, compile scripts + `manifest.yaml` (model files themselves never in git) |
| `docs/` | `protocol.md` (8 steps), `hardware/` spec sheets, decisions, problems, journal |
| `report/` | LaTeX report (≤15 pages), professor's outline |

## Quick start: clone to figures (VM, Ubuntu 22.04)
```bash
gh repo clone TrashRobotEdge/EdgeTrash -- -b benchmark-kit   # or git clone -b benchmark-kit https://github.com/TrashRobotEdge/EdgeTrash.git
cd EdgeTrash
bash setup/setup.sh --config vm-dev   # ~7 min. Say yes to the COCO download (1 GB). The smoke test fails here: no model files yet
source .venv/bin/activate && unset PYTHONPATH   # every new shell. unset: a sourced ROS leaks its packages in and breaks pytest
bash bench/dryrun.sh models    # ~20 min: builds every model file into models/files/
bash bench/dryrun.sh measure   # ~50 min: accuracy, latency, results/summary.csv, results/accuracy.csv, results/figures/
```
- `-b benchmark-kit`: until PR #46 is merged.
- Ubuntu has no `python` command, only `python3`. Inside the venv, `python` works.
- Ubuntu 24.04 host: use the 22.04 VM. ROS Humble and the Hailo compiler (Python 3.10) need 22.04.
- Pis (USB bundle, class-day runbook) and the Hailo compiler: [setup/README.md](setup/README.md).

## Reproduce one configuration
With the venv active and model files built (above):
```bash
python bench/run.py --config bench/configs/<device>.yaml --variant <variant> --rep 0     # one run
python bench/sweep.py --config bench/configs/<device>.yaml                              # idle + all variants x 5 reps
python bench/analyze.py                                                                 # every table and figure
```
How each model file was built: its `made_by` line in [models/manifest.yaml](models/manifest.yaml). Protocol: [docs/protocol.md](docs/protocol.md).
